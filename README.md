# Movy Study Plan

Simulador local para criar cotações e study plans da Movy Education.

## Como usar

Abra `index.html` no navegador ou acesse a versão publicada no GitHub Pages.

Nesta primeira versão, os planos ficam salvos no `localStorage` do navegador. Login, banco de dados e sincronização em nuvem ficam para uma etapa futura.

## Recursos

- Cursos ELICOS, VET e Higher Education.
- Cálculo de tuition, material, matrícula, bolsa/desconto e custos adicionais.
- Cronograma com semanas de estudo e férias.
- Sugestão de parcelamento por tipo de curso.
- Prévia pronta para imprimir ou salvar como PDF.
