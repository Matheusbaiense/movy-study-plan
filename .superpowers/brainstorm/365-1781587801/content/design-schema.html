Design — Seção 1: Schema & Arquitetura

Módulo HR · Time Tracker + Invoice Generator

Onde vive no app

app/[locale]/(protected)/
hr/ ← nova seção
page.tsx ← dashboard de ponto (entradas recentes)
clock/
page.tsx ← clock in/out do funcionário
timesheets/
page.tsx ← lista de entradas (admin aprova)
invoices/
page.tsx ← lista de invoices geradas
[id]/print/page.tsx ← Tax Invoice PDF (window.print)
components/hr/ ← componentes do módulo
TaxInvoice.tsx ← espelho do StudyPlanProposal.tsx
ClockWidget.tsx ← botão in/out com timer
TimesheetTable.tsx ← tabela de entradas + aprovação
lib/hr/ ← lógica pura
calculations.ts ← horas × taxa + multiplicadores
queries.ts ← queries org-scoped

Tabelas — 4 novas, todas org_id + RLS

employee_profiles
id uuid PK
org_id uuid FK
profile_id uuid FK → profiles
abn text
bank_name text
bsb text
account_number text
account_name text
hourly_rate_in_cents bigint
currency_code text default 'AUD'
metadata jsonb
external_id text
time_entries
id uuid PK
org_id uuid FK
employee_id uuid FK → employee_profiles
clock_in timestamptz NOT NULL
clock_out timestamptz
description text
day_type text (weekday/saturday/sunday/public_holiday)
status text (pending/approved/rejected)
approved_by uuid FK → profiles
invoice_id uuid FK → hr_invoices (nullable)
metadata jsonb
hr_rate_rules
id uuid PK
org_id uuid FK
name text (ex: "Saturday Penalty")
day_type text (weekday/saturday/sunday/public_holiday)
multiplier numeric (ex: 1.5, 2.0)
applies_from date
applies_until date (nullable)
metadata jsonb
hr_invoices
id uuid PK
org_id uuid FK
employee_id uuid FK → employee_profiles
invoice_number text (auto: INV-{employee}-{seq})
period_start date
period_end date
total_cents bigint (snapshot)
currency_code text default 'AUD'
status text (draft/issued/paid)
issued_at timestamptz
paid_at timestamptz
metadata jsonb
external_id text
